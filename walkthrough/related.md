## Free tools by Zovo that go with mind maps

- XMind Viewer & Mind Map Viewer: opens XMind files, and shows FreeMind and OPML maps read-only.
- Markdown Editor: write Markdown with a rich text view.
- Mermaid Viewer: a live preview of Mermaid diagrams.

Each link opens the extension page in VS Code. Nothing installs until you click Install there.
