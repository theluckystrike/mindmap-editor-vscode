## Keys in the map

| Key | What it does |
|---|---|
| Tab | Add a child topic |
| Enter | Add a topic after the selected one |
| Shift+Enter | Add a topic before the selected one |
| F2 or double-click | Rename |
| Delete | Delete the topic and its branch |
| Space | Collapse or expand the branch |
| Arrow keys | Move between topics |
| Ctrl+Z / Cmd+Z | Undo |

Drag a topic onto another to make it a child there. Drop it on the top or bottom edge of a topic to put it before or after that topic.
