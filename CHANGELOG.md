# Changelog

## 0.1.0

- First release: .km, FreeMind .mm and OPML files open as an editable mind map. Keyboard editing (Tab, Enter, F2, Delete, Space, arrows), drag to move, collapse, notes, priority, progress, links, five layouts and theme colors. Saves back to the same format and keeps everything it does not change.
- Zovo Pro tools, 1 free try each: export picture (PNG, SVG, PDF), convert maps (KM, MM, OPML, Markdown; a file or a folder) and a task view with CSV and Markdown export.
